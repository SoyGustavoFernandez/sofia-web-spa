# SOFIA - Frontend SPA

Aplicación Web SPA para SOFIA (Sistema Optimizado Farmacéutico con Inteligencia Artificial) basada en Angular 18+ y la plantilla MatDash PRO.

## Desarrollo local

1. Instalar dependencias: `npm install`
2. Iniciar el servidor de desarrollo: `npm start`
3. Abrir la aplicación en `http://localhost:4200/`
